# Charte vidéo FinanceData : « Le Point »

**Idée :** dans un feed saturé de bruit, FinanceData *fait le point* : il isole l'information qui compte.
**Signature :** un seul point rouge par écran. Il marque la valeur clé, étiquette les personnes, sert de puce à la règle, fait les transitions et devient le logo final.

- Charte complète (12 planches) : `charte/b1.png` → `charte/b12.png` (aperçus `planches/charte-1.jpg`, `planches/charte-2.jpg`), source `charte.html`.
- Extrait animé : `demo/renders/demo-charte.mp4` (source `demo/index.html`).
- Stratégie : `STRATEGIE.md` · Brainstorming : `BRAINSTORM.md`.
