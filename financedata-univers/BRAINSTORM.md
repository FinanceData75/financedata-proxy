# FinanceData : brainstorming de direction artistique

## 1. Diagnostic
Les pistes précédentes proposaient des *styles* (textures, typos, effets) sans *idée*. Une DA de média part de trois questions :
1. **Qui sommes-nous ?** (positionnement, ce qu'on refuse)
2. **Qu'est-ce qu'on reconnaît en 0,5 s dans le feed ?** (un code propriétaire)
3. **Peut-on le produire chaque semaine ?** (un système, pas un one-shot)

## 2. Plateforme de marque
- **Cible** : 25–35 ans, curieux, débutants à intermédiaires, qui scrollent vite.
- **Promesse** : *les mécanismes invisibles des marchés* (déjà dans chaque CTA).
- **Personnalité** : le décrypteur calme dans un monde bruyant.
- **Ennemis** : les finfluenceurs criards (Lamborghini, néon, emojis, « devenez riche ») et la vidéo IA générique.
- **Valeurs visuelles** : vérité (vraies sources), clarté, calme, élégance.

## 3. Benchmark : ce qui rend une marque reconnaissable
| Média | Code propriétaire | Leçon |
|---|---|---|
| Vox (Explained) | Surligneur jaune sur de vrais documents | Un geste unique appliqué à du matériel réel |
| The Economist (films) | Rouge Economist, retenue éditoriale | Une couleur = une signature |
| Bloomberg Originals | Gros chiffres, archives réelles | Les données comme héroïnes |
| Johnny Harris | Cartes et documents manipulés, son visage | Le tactile et l'humain battent le lisse |
| HugoDécrypte | Le visage + une couleur simple | La confiance passe par une personne |
| Kurzgesagt | Univers 100 % illustré | À éviter pour nous : trop proche de l'IA aujourd'hui |

**Conclusion** : les marques fortes ont **un code propriétaire appliqué à du matériel réel**, plus **un ancrage humain** (voix ou visage).

## 4. Territoires explorés
| | Territoire | Idée | Risque |
|---|---|---|---|
| A | **Le Révélateur** | Le monde en bichromie bleue, un viseur révèle le mécanisme caché | Peut devenir un gimmick si surutilisé |
| B | **La Salle des marchés** | Esthétique terminal Bloomberg, tickers, données denses | Cliché, s'éloigne du bleu FinanceData |
| C | **Les Archives** | Vraies unes de presse, dates, photos d'époque tramées | Droits sur les unes, effet rétro |
| D | **Le Laboratoire** | Les marchés étudiés comme une science : schémas, mesures | Froid, peu émotionnel |
| E | **L'Objet** | Chaque concept = un vrai objet filmé (élastique pour le RSI, thermomètre pour le VIX, tirelire…) sur fond bleu | Demande de filmer 5 s par vidéo |
| F | **Le Visage** | Lucas face caméra, graphismes minimaux | Demande d'apparaître à l'écran |
| G | **La Carte** | Les flux d'argent dessinés comme un plan de métro | Niche, difficile à décliner |

## 6. Recommandation : « Le réel, puis le mécanisme »
On combine les deux meilleurs territoires, qui racontent la même chose :
- **E, L'Objet, pour le hook** : la vidéo s'ouvre sur un vrai objet filmé qui incarne l'analogie du script (un élastique qu'on tend pour le RSI, un moniteur cardiaque pour le VIX). Impossible à confondre avec de l'IA, immédiatement mémorable.
- **A, Le Révélateur, comme système** : ensuite, le monde passe en bichromie bleue et le viseur révèle les vrais chiffres.
- **F, en touche légère** : votre voix, et votre visage ou vos mains de temps en temps dans le hook.

## 7. Le plan cohérent
### Structure fixe de chaque vidéo (60–70 s)
1. **Le réel** (0–4 s) : objet filmé ou vraie photo, la question qui accroche.
2. **La révélation** (4–15 s) : le viseur se pose, on nomme le mécanisme.
3. **La preuve** (15–50 s) : vrais graphiques, 2 ou 3 exemples datés et sourcés.
4. **La règle** (50–58 s) : une phrase, une image.
5. **La signature** (58–65 s) : logo dans le viseur, « Les mécanismes invisibles des marchés », abonnez-vous.

### Séries (un libellé mono en haut, même DA)
- **Le Guide** : un concept (RSI, VIX, CDS, obligations).
- **Décryptage** : l'actualité (Microsoft, LVMH, OpenAI).
- **Portrait** : un investisseur (Buffett, Ackman, Ronald Read).

### Charte
- Bleu #00194B dominant, blanc bleuté #EEF3FC, rouge #FF2E24 pour la seule valeur révélée.
- Photos réelles en bichromie ; l'objet filmé et les captures restent en couleurs réelles (la « preuve »).
- Typo : Big Shoulders pour les chiffres, Geist Mono pour les coordonnées et sources, Inter pour les sous-titres.
- Mouvement : 3 à 5 s par écran, coupes calées sur la voix, pas de zoom ni de tremblement.
- Son : la voix au centre, un seul son de marque (déclic du viseur), rien d'autre.

### Production
- **Vous** : le script validé, la voix, 5 s de l'objet filmé au téléphone (fond uni, lumière du jour), les photos si besoin.
- **Moi** : édition voix, bichromie, graphiques à partir des données réelles, montage, rendu.

### Déploiement et mesure
1. **Semaine 1** : 3 versions du hook RSI (objet / photo / chiffre), même corps de vidéo ; on compare la rétention à 3 s et à 10 s.
2. **Semaine 2** : on fige le template gagnant, on l'applique au VIX et au prochain Décryptage.
3. **Semaine 3–4** : carrousels et visuels de newsletter dans la même DA.
4. **KPI** : rétention à 3 s et 10 s, taux d'enregistrement, abonnés par vidéo.
